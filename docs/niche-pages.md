# Niche landing pages (SEO plan)

Purpose: capture niche searches. Keywords below are HYPOTHESES to validate with keyword research. No search-volume claims.

## Rules
- Start with 3-5 pages for offers that are Live or about to go live (see landing-brief section 4). Add more only when there is real content, a demo, or a client.
- Every page needs UNIQUE, useful content: real features for that niche, a real demo or screenshots when available, a niche-specific FAQ, a clear CTA.
  Do not clone one template across 50 slugs; near-duplicate or thin pages hurt SEO and trust.
- Pages for "Coming soon" niches: either skip, or publish one honest page with a waitlist. Never imply it is available.
- Check platform rules/terms before promoting niches that touch third-party platforms (for example game account or item trading) and regulated activities (bill payment, e-money).

## Page template
H1 (niche + outcome) -> one-sentence subhead -> 4-6 niche features -> "How it works" (4 steps) -> what can be customized (branding/config/add-ons)
-> demo or screenshots (placeholders if none) -> 3-4 niche FAQs -> CTA (WhatsApp) -> internal links to related niches.
